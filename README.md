# Cybersecurity Home Lab

## Overview

This project documents my hands-on cybersecurity home lab built using VirtualBox.

The lab simulates an enterprise environment where I practice network reconnaissance, vulnerability assessment, web application security testing, Linux and Windows administration, and security monitoring.

## Lab Architecture

The environment consists of:

- Kali Linux — Attacker machine
- Windows Server — Windows infrastructure
- Ubuntu/Debian Server — Linux infrastructure
- Vulnerable Web Application — DVWA / OWASP Juice Shop
- Vulnerable API — crAPI / VAmPI
- SIEM — Wazuh / Splunk

## Objectives

- Build a realistic cybersecurity testing environment
- Perform network reconnaissance
- Identify vulnerabilities
- Conduct web application security testing
- Monitor and analyze security logs
- Document findings and remediation
- Develop practical cybersecurity skills
