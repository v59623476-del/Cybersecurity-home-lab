# Lab Architecture

## Overview

This document describes the architecture of my cybersecurity home lab.

The environment is built using VirtualBox and contains attacker, infrastructure, vulnerable application, vulnerable API, and security monitoring components.

## Components

- Kali Linux — Attacker
- Windows Server — Windows infrastructure
- Ubuntu/Debian Server — Linux infrastructure
- Vulnerable Web Application
- Vulnerable API
- SIEM / Security Monitoring

## Purpose

The purpose of this lab is to create a controlled environment for practicing cybersecurity techniques including reconnaissance, vulnerability assessment, web application security testing, API security testing, log analysis, and security monitoring.
